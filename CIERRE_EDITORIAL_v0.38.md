# Cierre editorial profesional — versión 0.38

Esta versión incorpora la estructura editorial necesaria para una primera edición profesional:

- portada;
- créditos editoriales;
- forma de citar;
- prefacio;
- agradecimientos;
- presentación e introducción;
- cuerpo de 22 capítulos;
- glosario;
- referencias;
- índice temático;
- semblanza del autor.

La siguiente etapa consiste en renderizar, revisar visualmente el PDF y la web, corregir defectos de maquetación y preparar la versión candidata 1.0.
