# Corrección LaTeX de figuras de regresión — versión 0.40.2

El error se originó en la expresión `\(\hat y\)` del texto explicativo de la figura de regresión lineal múltiple.

Se reemplazó por:

```markdown
$\hat{y}$
```

También se normalizaron las expresiones nuevas de regresión logística y regresión lineal simple.
