12  Regularización y control de la complejidad

Introducción

La regularización modifica el problema de ajuste para controlar la complejidad efectiva, estabilizar estimaciones y mejorar el desempeño fuera de muestra. Puede expresarse como penalización, restricción, parada temprana, reducción de dimensión o elección de una clase de hipótesis más pequeña (Tikhonov 1963; Tibshirani 1996; Hastie et al. 2009).

La regularización es una de las ideas centrales del aprendizaje automático moderno. Su propósito es controlar la complejidad de un modelo para mejorar su capacidad de generalización. En lugar de minimizar únicamente el error de entrenamiento, se añade una penalización que desalienta soluciones excesivamente flexibles, inestables o difíciles de interpretar.

La regularización puede entenderse desde distintos puntos de vista:

  • como una penalización añadida a la función de pérdida;
  • como una restricción sobre el tamaño de los parámetros;
  • como una forma de reducir varianza;
  • como una estrategia para combatir la multicolinealidad;
  • como un mecanismo de selección de variables;
  • como una forma de incorporar información previa.

En este capítulo se desarrollan formalmente ridge, LASSO y elastic net, así como sus interpretaciones geométricas y estadísticas.

ImportanteDefinición esencial

Regularizar significa controlar la complejidad efectiva para reducir sobreajuste.

Motivación

Considere el modelo lineal

\[ \mathbf{y} = \mathbf{X}\boldsymbol{\beta} + \boldsymbol{\varepsilon}. \]

El estimador de mínimos cuadrados es

\[ \widehat{\boldsymbol{\beta}}_{OLS} = \arg\min_{\boldsymbol{\beta}} \left\| \mathbf{y} - \mathbf{X}\boldsymbol{\beta} \right\|_2^2. \]

Si \(\mathbf{X}^{\mathsf T}\mathbf{X}\) es invertible,

\[ \widehat{\boldsymbol{\beta}}_{OLS} = \left( \mathbf{X}^{\mathsf T}\mathbf{X} \right)^{-1} \mathbf{X}^{\mathsf T}\mathbf{y}. \]

Sin embargo, este estimador puede presentar problemas cuando:

  • existen variables altamente correlacionadas;
  • \(p\) es grande;
  • \(p\geq n\);
  • hay ruido considerable;
  • el modelo tiene demasiada flexibilidad;
  • se desea seleccionar variables.

Problemas de multicolinealidad

Cuando algunas columnas de \(\mathbf{X}\) están altamente correlacionadas, la matriz

\[ \mathbf{X}^{\mathsf T}\mathbf{X} \]

puede estar mal condicionada.

Esto provoca:

  • coeficientes inestables;
  • gran varianza;
  • sensibilidad a pequeñas perturbaciones;
  • signos difíciles de interpretar;
  • predicciones poco robustas.

Problema penalizado general

Definición 12.1 Un problema de regularización tiene la forma

\[ \widehat{\boldsymbol{\beta}} = \arg\min_{\boldsymbol{\beta}} \left\{ L(\boldsymbol{\beta}) + \lambda \Omega(\boldsymbol{\beta}) \right\}, \]

donde:

  • \(L(\boldsymbol{\beta})\) es la pérdida;
  • \(\Omega(\boldsymbol{\beta})\) mide complejidad;
  • \(\lambda\geq 0\) controla la intensidad de regularización.

Cuando

\[ \lambda=0, \]

se recupera el modelo sin penalización.

Cuando \(\lambda\) aumenta, la penalización adquiere mayor peso.

Interpretación del parámetro de regularización

Un valor pequeño de \(\lambda\):

  • permite mayor flexibilidad;
  • reduce sesgo;
  • puede aumentar varianza.

Un valor grande:

  • reduce la magnitud de los coeficientes;
  • aumenta estabilidad;
  • puede aumentar sesgo;
  • puede producir subajuste.

Formulación restringida

El problema penalizado puede relacionarse con

\[ \min_{\boldsymbol{\beta}} L(\boldsymbol{\beta}) \]

sujeto a

\[ \Omega(\boldsymbol{\beta}) \leq t. \]

Existe una correspondencia entre \(\lambda\) y \(t\), bajo condiciones regulares.

La forma penalizada utiliza \(\lambda\); la forma restringida limita directamente la complejidad.

Regresión ridge

Definición 12.2 La regresión ridge minimiza

\[ J_{ridge}(\boldsymbol{\beta}) = \left\| \mathbf{y} - \mathbf{X}\boldsymbol{\beta} \right\|_2^2 + \lambda \left\| \boldsymbol{\beta} \right\|_2^2. \]

La penalización es

\[ \left\| \boldsymbol{\beta} \right\|_2^2 = \sum_{j=1}^{p} \beta_j^2. \]

Habitualmente el intercepto no se penaliza.

Forma matricial de ridge

La función objetivo puede escribirse como

\[ J_{ridge}(\boldsymbol{\beta}) = (\mathbf{y}-\mathbf{X}\boldsymbol{\beta})^{\mathsf T} (\mathbf{y}-\mathbf{X}\boldsymbol{\beta}) + \lambda \boldsymbol{\beta}^{\mathsf T}\boldsymbol{\beta}. \]

Derivación del estimador ridge

Derivando respecto de \(\boldsymbol{\beta}\),

\[ \nabla J_{ridge} = -2\mathbf{X}^{\mathsf T} (\mathbf{y}-\mathbf{X}\boldsymbol{\beta}) + 2\lambda\boldsymbol{\beta}. \]

Igualando a cero,

\[ -2\mathbf{X}^{\mathsf T}\mathbf{y} + 2\mathbf{X}^{\mathsf T}\mathbf{X}\boldsymbol{\beta} + 2\lambda\boldsymbol{\beta} = \mathbf{0}. \]

Entonces,

\[ \left( \mathbf{X}^{\mathsf T}\mathbf{X} + \lambda\mathbf{I} \right) \boldsymbol{\beta} = \mathbf{X}^{\mathsf T}\mathbf{y}. \]

Por tanto,

\[ \widehat{\boldsymbol{\beta}}_{ridge} = \left( \mathbf{X}^{\mathsf T}\mathbf{X} + \lambda\mathbf{I} \right)^{-1} \mathbf{X}^{\mathsf T}\mathbf{y}. \]

Efecto sobre la invertibilidad

Incluso si

\[ \mathbf{X}^{\mathsf T}\mathbf{X} \]

es singular, para \(\lambda>0\),

\[ \mathbf{X}^{\mathsf T}\mathbf{X} + \lambda\mathbf{I} \]

es definida positiva y, por tanto, invertible.

Esta es una ventaja fundamental de ridge.

Interpretación espectral

Supóngase que

\[ \mathbf{X}^{\mathsf T}\mathbf{X} = \mathbf{Q} \boldsymbol{\Lambda} \mathbf{Q}^{\mathsf T}, \]

donde

\[ \boldsymbol{\Lambda} = \operatorname{diag} (\mu_1,\ldots,\mu_p). \]

Entonces,

\[ \left( \mathbf{X}^{\mathsf T}\mathbf{X} + \lambda\mathbf{I} \right)^{-1} = \mathbf{Q} \operatorname{diag} \left( \frac{1}{\mu_j+\lambda} \right) \mathbf{Q}^{\mathsf T}. \]

Ridge reduce con mayor intensidad las direcciones asociadas a valores propios pequeños.

Factores de contracción

En las coordenadas principales, el factor de contracción es

\[ \frac{\mu_j}{\mu_j+\lambda}. \]

Se cumple

\[ 0 \leq \frac{\mu_j}{\mu_j+\lambda} < 1. \]

Cuando \(\mu_j\) es pequeño, la contracción es mayor.

Sesgo de ridge

Condicionado a \(\mathbf{X}\),

\[ \mathbb{E} [ \widehat{\boldsymbol{\beta}}_{ridge} ] = \left( \mathbf{X}^{\mathsf T}\mathbf{X} + \lambda\mathbf{I} \right)^{-1} \mathbf{X}^{\mathsf T}\mathbf{X} \boldsymbol{\beta}. \]

Por tanto, ridge es sesgado cuando \(\lambda>0\).

Varianza de ridge

Si

\[ \operatorname{Var}(\boldsymbol{\varepsilon}) = \sigma^2\mathbf{I}, \]

entonces

\[ \operatorname{Var} ( \widehat{\boldsymbol{\beta}}_{ridge} ) = \sigma^2 \left( \mathbf{X}^{\mathsf T}\mathbf{X} + \lambda\mathbf{I} \right)^{-1} \mathbf{X}^{\mathsf T}\mathbf{X} \left( \mathbf{X}^{\mathsf T}\mathbf{X} + \lambda\mathbf{I} \right)^{-1}. \]

Ridge introduce sesgo, pero puede reducir considerablemente la varianza.

Ridge y el compromiso sesgo-varianza

El error cuadrático medio de los parámetros puede disminuir si la reducción de varianza compensa el aumento de sesgo.

Esta es la razón estadística de la regularización.

Geometría de ridge

La forma restringida es

\[ \min_{\boldsymbol{\beta}} \left\| \mathbf{y} - \mathbf{X}\boldsymbol{\beta} \right\|_2^2 \]

sujeto a

\[ \sum_{j=1}^{p} \beta_j^2 \leq t. \]

La región factible es una esfera o circunferencia \(L_2\).

La solución aparece donde una curva de nivel de la pérdida toca la región restringida.

Estandarización

Ridge depende de la escala de las variables.

Antes de ajustar, suele utilizarse

\[ z_{ij} = \frac{ x_{ij}-\overline{x}_j }{ s_j }. \]

Sin estandarización, las variables con escalas grandes reciben una penalización relativa diferente.

LASSO

Definición 12.3 LASSO minimiza

\[ J_{lasso}(\boldsymbol{\beta}) = \left\| \mathbf{y} - \mathbf{X}\boldsymbol{\beta} \right\|_2^2 + \lambda \left\| \boldsymbol{\beta} \right\|_1. \]

La norma \(L_1\) es

\[ \left\| \boldsymbol{\beta} \right\|_1 = \sum_{j=1}^{p} |\beta_j|. \]

Forma restringida de LASSO

\[ \min_{\boldsymbol{\beta}} \left\| \mathbf{y} - \mathbf{X}\boldsymbol{\beta} \right\|_2^2 \]

sujeto a

\[ \sum_{j=1}^{p} |\beta_j| \leq t. \]

No diferenciabilidad

La función

\[ |\beta| \]

no es diferenciable en

\[ \beta=0. \]

Por tanto, LASSO no posee una solución matricial cerrada análoga a ridge.

Se utilizan métodos como:

  • descenso por coordenadas;
  • subgradientes;
  • LARS;
  • métodos proximales.

Subgradiente

Para

\[ g(\beta)=|\beta|, \]

el subgradiente es

\[ \partial g(\beta) = \begin{cases} \{1\}, & \beta>0,\\ [-1,1], & \beta=0,\\ \{-1\}, & \beta<0. \end{cases} \]

Las condiciones óptimas se expresan mediante subgradientes.

Operador soft-thresholding

Definición 12.4 El operador de umbral suave se define como

\[ S(z,\gamma) = \operatorname{sign}(z) \max \{ |z|-\gamma, 0 \}. \]

Este operador reduce la magnitud y puede producir exactamente cero.

Caso ortonormal

Si

\[ \mathbf{X}^{\mathsf T}\mathbf{X} = \mathbf{I}, \]

la solución LASSO tiene la forma

\[ \widehat{\beta}_j = S \left( \widehat{\beta}_{j,OLS}, \frac{\lambda}{2} \right), \]

según la convención de escala utilizada.

Geometría de LASSO

La región

\[ \left\| \boldsymbol{\beta} \right\|_1 \leq t \]

tiene forma de rombo en dos dimensiones.

Sus vértices están sobre los ejes coordenados. Las curvas de nivel de la pérdida tienen mayor probabilidad de tocar un vértice.

Por ello, LASSO produce coeficientes exactamente iguales a cero.

Selección de variables

Si

\[ \widehat{\beta}_j=0, \]

la variable \(j\) queda excluida del modelo.

LASSO realiza simultáneamente:

  • ajuste;
  • contracción;
  • selección de variables.

Limitaciones de LASSO

LASSO puede presentar dificultades cuando:

  • las variables están fuertemente correlacionadas;
  • \(p\gg n\);
  • existen grupos de variables similares;
  • la señal está distribuida entre muchas variables pequeñas.

En grupos correlacionados, puede seleccionar una variable y excluir otras de forma inestable.

Elastic net

Definición 12.5 Elastic net combina penalizaciones \(L_1\) y \(L_2\):

\[ J_{EN}(\boldsymbol{\beta}) = \left\| \mathbf{y} - \mathbf{X}\boldsymbol{\beta} \right\|_2^2 + \lambda_1 \left\| \boldsymbol{\beta} \right\|_1 + \lambda_2 \left\| \boldsymbol{\beta} \right\|_2^2. \]

Otra parametrización es

\[ J_{EN}(\boldsymbol{\beta}) = L(\boldsymbol{\beta}) + \lambda \left[ \alpha \left\| \boldsymbol{\beta} \right\|_1 + (1-\alpha) \left\| \boldsymbol{\beta} \right\|_2^2 \right], \]

con

\[ 0\leq\alpha\leq 1. \]

Casos particulares

Si

\[ \alpha=1, \]

se obtiene LASSO.

Si

\[ \alpha=0, \]

se obtiene ridge.

Si

\[ 0<\alpha<1, \]

se obtiene elastic net.

Ventaja de elastic net

Elastic net puede:

  • seleccionar variables;
  • estabilizar grupos correlacionados;
  • funcionar mejor cuando \(p>n\);
  • combinar esparsidad y estabilidad.

Caminos de regularización

Al variar \(\lambda\), se obtiene una trayectoria

\[ \widehat{\boldsymbol{\beta}}(\lambda). \]

Cuando \(\lambda\to 0\), la solución se aproxima al modelo no regularizado.

Cuando \(\lambda\to\infty\), los coeficientes tienden a cero.

Valor máximo del parámetro de regularización

En LASSO existe un valor suficientemente grande

\[ \lambda_{\max} \]

para el cual todos los coeficientes penalizados son cero.

Los algoritmos suelen construir una secuencia decreciente desde \(\lambda_{\max}\).

Selección del parámetro de regularización

La práctica habitual es seleccionar \(\lambda\) mediante validación cruzada:

\[ \widehat{\lambda} = \arg\min_{\lambda} CV(\lambda). \]

También puede utilizarse la regla de un error estándar para elegir una solución más regularizada y parsimoniosa.

Ridge como estimación bayesiana

Supóngase el modelo gaussiano

\[ \mathbf{y} \mid \boldsymbol{\beta} \sim N( \mathbf{X}\boldsymbol{\beta}, \sigma^2\mathbf{I} ). \]

Considérese la previa

\[ \boldsymbol{\beta} \sim N( \mathbf{0}, \tau^2\mathbf{I} ). \]

El estimador MAP minimiza

\[ \frac{1}{2\sigma^2} \left\| \mathbf{y} - \mathbf{X}\boldsymbol{\beta} \right\|_2^2 + \frac{1}{2\tau^2} \left\| \boldsymbol{\beta} \right\|_2^2. \]

Por tanto, ridge corresponde a una previa normal.

LASSO como estimación bayesiana

Si la previa de cada coeficiente es Laplace,

\[ p(\beta_j) \propto \exp \left( -\frac{|\beta_j|}{b} \right), \]

el estimador MAP conduce a una penalización \(L_1\).

Regularización en regresión logística

La pérdida logística penalizada es

\[ J(\boldsymbol{\beta}) = - \sum_{i=1}^{n} \left[ y_i\log\pi_i + (1-y_i)\log(1-\pi_i) \right] + \lambda \Omega(\boldsymbol{\beta}). \]

Puede utilizarse:

  • ridge;
  • LASSO;
  • elastic net.

Regularización en redes neuronales

Weight decay

Se añade

\[ \lambda \sum_l \left\| \mathbf{W}^{(l)} \right\|_F^2. \]

Dropout

Durante el entrenamiento, algunas activaciones se eliminan aleatoriamente.

Early stopping

Se detiene el entrenamiento cuando el error de validación deja de mejorar.

Data augmentation

Se generan transformaciones de los datos para reducir sobreajuste.

Regularización en árboles

En árboles, el control de complejidad se realiza mediante:

  • profundidad máxima;
  • número mínimo de observaciones por nodo;
  • poda;
  • penalización por número de hojas.

La regularización no siempre adopta la forma de una norma.

Regularización explícita e implícita

La regularización explícita aparece directamente en la función objetivo.

La regularización implícita puede provenir de:

  • optimización;
  • arquitectura;
  • inicialización;
  • detención temprana;
  • ruido en el entrenamiento.

Grados de libertad efectivos

En ridge, los valores ajustados son

\[ \widehat{\mathbf{y}} = \mathbf{H}_{\lambda}\mathbf{y}, \]

donde

\[ \mathbf{H}_{\lambda} = \mathbf{X} \left( \mathbf{X}^{\mathsf T}\mathbf{X} + \lambda\mathbf{I} \right)^{-1} \mathbf{X}^{\mathsf T}. \]

Los grados de libertad efectivos son

\[ df(\lambda) = \operatorname{tr} ( \mathbf{H}_{\lambda} ). \]

Al aumentar \(\lambda\), disminuyen los grados de libertad efectivos.

Relación con la estabilidad

Un algoritmo es estable si pequeñas modificaciones de la muestra producen cambios pequeños en el modelo.

Ridge suele aumentar estabilidad al evitar coeficientes extremos.

La estabilidad contribuye a reducir la brecha de generalización.

Variables categóricas

Cuando una variable categórica se codifica con varias variables indicadoras, penalizar cada coeficiente por separado puede ser inadecuado.

Pueden utilizarse extensiones como:

  • group LASSO;
  • sparse group LASSO.

Group LASSO

Si los parámetros se agrupan en \(G\) bloques,

\[ \boldsymbol{\beta}_1,\ldots,\boldsymbol{\beta}_G, \]

la penalización es

\[ \sum_{g=1}^{G} w_g \left\| \boldsymbol{\beta}_g \right\|_2. \]

Puede eliminar grupos completos de variables.

Regularización adaptativa

Adaptive LASSO utiliza pesos:

\[ \sum_{j=1}^{p} w_j|\beta_j|. \]

Los pesos pueden depender de estimaciones iniciales.

Esto permite penalizar menos los coeficientes aparentemente importantes.

Regularización y causalidad

La selección de variables predictivas no equivale a identificar variables causales.

Un coeficiente cero puede deberse a:

  • correlación con otras variables;
  • penalización;
  • falta de potencia;
  • estructura de la muestra.

La regularización mejora predicción, pero no resuelve por sí sola problemas causales.

Conexión con R

Código 
# Requiere glmnet
library(glmnet)

set.seed(123)

n <- 100
p <- 10

X <- matrix(rnorm(n * p), nrow = n, ncol = p)

beta_real <- c(3, -2, 1.5, rep(0, p - 3))

y <- as.vector(X %*% beta_real + rnorm(n))

# Ridge: alpha = 0
ajuste_ridge <- cv.glmnet(
  X,
  y,
  alpha = 0
)

ajuste_ridge$lambda.min

# LASSO: alpha = 1
ajuste_lasso <- cv.glmnet(
  X,
  y,
  alpha = 1
)

ajuste_lasso$lambda.min

coef(ajuste_lasso, s = "lambda.min")

# Elastic net
ajuste_en <- cv.glmnet(
  X,
  y,
  alpha = 0.5
)

coef(ajuste_en, s = "lambda.1se")

Ejemplo numérico ridge

Considere

\[ \mathbf{X}^{\mathsf T}\mathbf{X} = \begin{pmatrix} 4 & 3\\ 3 & 2.5 \end{pmatrix}, \]

y

\[ \mathbf{X}^{\mathsf T}\mathbf{y} = \begin{pmatrix} 10\\ 8 \end{pmatrix}. \]

Con

\[ \lambda=1, \]

se obtiene

\[ \mathbf{X}^{\mathsf T}\mathbf{X} + \lambda\mathbf{I} = \begin{pmatrix} 5 & 3\\ 3 & 3.5 \end{pmatrix}. \]

La solución ridge es

\[ \widehat{\boldsymbol{\beta}}_{ridge} = \begin{pmatrix} 5 & 3\\ 3 & 3.5 \end{pmatrix}^{-1} \begin{pmatrix} 10\\ 8 \end{pmatrix}. \]

Este sistema es más estable que el sistema sin penalización.

Comparación conceptual

Método Penalización Selección de variables Estabilidad
Ridge \(L_2\) No exacta Alta
LASSO \(L_1\) Sí Puede ser inestable con correlación
Elastic net \(L_1+L_2\) Sí Mayor con variables correlacionadas

Errores frecuentes

  1. Penalizar variables sin estandarizarlas.
  2. Penalizar el intercepto sin intención.
  3. Seleccionar \(\lambda\) usando el conjunto de prueba.
  4. Interpretar coeficientes LASSO como evidencia causal.
  5. Suponer que LASSO siempre selecciona la variable correcta.
  6. Confundir coeficiente pequeño con irrelevancia absoluta.
  7. Ignorar la inestabilidad entre variables correlacionadas.
  8. Comparar soluciones obtenidas con escalas distintas.
  9. Utilizar regularización sin recalibrar el modelo cuando sea necesario.
  10. Reportar únicamente \(\lambda_{min}\) sin considerar parsimonia.

# Regularización y control de la complejidad {#sec-regularizacion}

## Introducción {.unnumbered}

La regularización modifica el problema de ajuste para controlar la complejidad efectiva, estabilizar estimaciones y mejorar el desempeño fuera de muestra. Puede expresarse como penalización, restricción, parada temprana, reducción de dimensión o elección de una clase de hipótesis más pequeña [@tikhonov1963solution; @tibshirani1996regression; @hastie2009elements].

La regularización es una de las ideas centrales del aprendizaje automático moderno. Su propósito es controlar la complejidad de un modelo para mejorar su capacidad de generalización. En lugar de minimizar únicamente el error de entrenamiento, se añade una penalización que desalienta soluciones excesivamente flexibles, inestables o difíciles de interpretar.

La regularización puede entenderse desde distintos puntos de vista:

- como una penalización añadida a la función de pérdida;
- como una restricción sobre el tamaño de los parámetros;
- como una forma de reducir varianza;
- como una estrategia para combatir la multicolinealidad;
- como un mecanismo de selección de variables;
- como una forma de incorporar información previa.

En este capítulo se desarrollan formalmente ridge, LASSO y elastic net, así como sus interpretaciones geométricas y estadísticas.

::: {.callout-important title="Definición esencial"}
Regularizar significa controlar la complejidad efectiva para reducir sobreajuste.
:::

## Motivación {.unnumbered}

Considere el modelo lineal

$$
\mathbf{y}
=
\mathbf{X}\boldsymbol{\beta}
+
\boldsymbol{\varepsilon}.
$$

El estimador de mínimos cuadrados es

$$
\widehat{\boldsymbol{\beta}}_{OLS}
=
\arg\min_{\boldsymbol{\beta}}
\left\|
\mathbf{y}
-
\mathbf{X}\boldsymbol{\beta}
\right\|_2^2.
$$

Si $\mathbf{X}^{\mathsf T}\mathbf{X}$ es invertible,

$$
\widehat{\boldsymbol{\beta}}_{OLS}
=
\left(
\mathbf{X}^{\mathsf T}\mathbf{X}
\right)^{-1}
\mathbf{X}^{\mathsf T}\mathbf{y}.
$$

Sin embargo, este estimador puede presentar problemas cuando:

- existen variables altamente correlacionadas;
- $p$ es grande;
- $p\geq n$;
- hay ruido considerable;
- el modelo tiene demasiada flexibilidad;
- se desea seleccionar variables.

## Problemas de multicolinealidad {.unnumbered}

Cuando algunas columnas de $\mathbf{X}$ están altamente correlacionadas, la matriz

$$
\mathbf{X}^{\mathsf T}\mathbf{X}
$$

puede estar mal condicionada.

Esto provoca:

- coeficientes inestables;
- gran varianza;
- sensibilidad a pequeñas perturbaciones;
- signos difíciles de interpretar;
- predicciones poco robustas.

## Problema penalizado general {.unnumbered}

::: {#def-regularizacion-general}
Un problema de regularización tiene la forma

$$
\widehat{\boldsymbol{\beta}}
=
\arg\min_{\boldsymbol{\beta}}
\left\{
L(\boldsymbol{\beta})
+
\lambda
\Omega(\boldsymbol{\beta})
\right\},
$$

donde:

- $L(\boldsymbol{\beta})$ es la pérdida;
- $\Omega(\boldsymbol{\beta})$ mide complejidad;
- $\lambda\geq 0$ controla la intensidad de regularización.
:::

Cuando

$$
\lambda=0,
$$

se recupera el modelo sin penalización.

Cuando $\lambda$ aumenta, la penalización adquiere mayor peso.

## Interpretación del parámetro de regularización {.unnumbered}

Un valor pequeño de $\lambda$:

- permite mayor flexibilidad;
- reduce sesgo;
- puede aumentar varianza.

Un valor grande:

- reduce la magnitud de los coeficientes;
- aumenta estabilidad;
- puede aumentar sesgo;
- puede producir subajuste.

## Formulación restringida {.unnumbered}

El problema penalizado puede relacionarse con

$$
\min_{\boldsymbol{\beta}}
L(\boldsymbol{\beta})
$$

sujeto a

$$
\Omega(\boldsymbol{\beta})
\leq t.
$$

Existe una correspondencia entre $\lambda$ y $t$, bajo condiciones regulares.

La forma penalizada utiliza $\lambda$; la forma restringida limita directamente la complejidad.

## Regresión ridge {.unnumbered}

::: {#def-ridge}
La regresión ridge minimiza

$$
J_{ridge}(\boldsymbol{\beta})
=
\left\|
\mathbf{y}
-
\mathbf{X}\boldsymbol{\beta}
\right\|_2^2
+
\lambda
\left\|
\boldsymbol{\beta}
\right\|_2^2.
$$
:::

La penalización es

$$
\left\|
\boldsymbol{\beta}
\right\|_2^2
=
\sum_{j=1}^{p}
\beta_j^2.
$$

Habitualmente el intercepto no se penaliza.

## Forma matricial de ridge {.unnumbered}

La función objetivo puede escribirse como

$$
J_{ridge}(\boldsymbol{\beta})
=
(\mathbf{y}-\mathbf{X}\boldsymbol{\beta})^{\mathsf T}
(\mathbf{y}-\mathbf{X}\boldsymbol{\beta})
+
\lambda
\boldsymbol{\beta}^{\mathsf T}\boldsymbol{\beta}.
$$

## Derivación del estimador ridge {.unnumbered}

Derivando respecto de $\boldsymbol{\beta}$,

$$
\nabla J_{ridge}
=
-2\mathbf{X}^{\mathsf T}
(\mathbf{y}-\mathbf{X}\boldsymbol{\beta})
+
2\lambda\boldsymbol{\beta}.
$$

Igualando a cero,

$$
-2\mathbf{X}^{\mathsf T}\mathbf{y}
+
2\mathbf{X}^{\mathsf T}\mathbf{X}\boldsymbol{\beta}
+
2\lambda\boldsymbol{\beta}
=
\mathbf{0}.
$$

Entonces,

$$
\left(
\mathbf{X}^{\mathsf T}\mathbf{X}
+
\lambda\mathbf{I}
\right)
\boldsymbol{\beta}
=
\mathbf{X}^{\mathsf T}\mathbf{y}.
$$

Por tanto,

$$
\widehat{\boldsymbol{\beta}}_{ridge}
=
\left(
\mathbf{X}^{\mathsf T}\mathbf{X}
+
\lambda\mathbf{I}
\right)^{-1}
\mathbf{X}^{\mathsf T}\mathbf{y}.
$$

## Efecto sobre la invertibilidad {.unnumbered}

Incluso si

$$
\mathbf{X}^{\mathsf T}\mathbf{X}
$$

es singular, para $\lambda>0$,

$$
\mathbf{X}^{\mathsf T}\mathbf{X}
+
\lambda\mathbf{I}
$$

es definida positiva y, por tanto, invertible.

Esta es una ventaja fundamental de ridge.

## Interpretación espectral {.unnumbered}

Supóngase que

$$
\mathbf{X}^{\mathsf T}\mathbf{X}
=
\mathbf{Q}
\boldsymbol{\Lambda}
\mathbf{Q}^{\mathsf T},
$$

donde

$$
\boldsymbol{\Lambda}
=
\operatorname{diag}
(\mu_1,\ldots,\mu_p).
$$

Entonces,

$$
\left(
\mathbf{X}^{\mathsf T}\mathbf{X}
+
\lambda\mathbf{I}
\right)^{-1}
=
\mathbf{Q}
\operatorname{diag}
\left(
\frac{1}{\mu_j+\lambda}
\right)
\mathbf{Q}^{\mathsf T}.
$$

Ridge reduce con mayor intensidad las direcciones asociadas a valores propios pequeños.

## Factores de contracción {.unnumbered}

En las coordenadas principales, el factor de contracción es

$$
\frac{\mu_j}{\mu_j+\lambda}.
$$

Se cumple

$$
0
\leq
\frac{\mu_j}{\mu_j+\lambda}
<
1.
$$

Cuando $\mu_j$ es pequeño, la contracción es mayor.

## Sesgo de ridge {.unnumbered}

Condicionado a $\mathbf{X}$,

$$
\mathbb{E}
[
\widehat{\boldsymbol{\beta}}_{ridge}
]
=
\left(
\mathbf{X}^{\mathsf T}\mathbf{X}
+
\lambda\mathbf{I}
\right)^{-1}
\mathbf{X}^{\mathsf T}\mathbf{X}
\boldsymbol{\beta}.
$$

Por tanto, ridge es sesgado cuando $\lambda>0$.

## Varianza de ridge {.unnumbered}

Si

$$
\operatorname{Var}(\boldsymbol{\varepsilon})
=
\sigma^2\mathbf{I},
$$

entonces

$$
\operatorname{Var}
(
\widehat{\boldsymbol{\beta}}_{ridge}
)
=
\sigma^2
\left(
\mathbf{X}^{\mathsf T}\mathbf{X}
+
\lambda\mathbf{I}
\right)^{-1}
\mathbf{X}^{\mathsf T}\mathbf{X}
\left(
\mathbf{X}^{\mathsf T}\mathbf{X}
+
\lambda\mathbf{I}
\right)^{-1}.
$$

Ridge introduce sesgo, pero puede reducir considerablemente la varianza.

## Ridge y el compromiso sesgo-varianza {.unnumbered}

El error cuadrático medio de los parámetros puede disminuir si la reducción de varianza compensa el aumento de sesgo.

Esta es la razón estadística de la regularización.

## Geometría de ridge {.unnumbered}

La forma restringida es

$$
\min_{\boldsymbol{\beta}}
\left\|
\mathbf{y}
-
\mathbf{X}\boldsymbol{\beta}
\right\|_2^2
$$

sujeto a

$$
\sum_{j=1}^{p}
\beta_j^2
\leq
t.
$$

La región factible es una esfera o circunferencia $L_2$.

La solución aparece donde una curva de nivel de la pérdida toca la región restringida.

## Estandarización {.unnumbered}

Ridge depende de la escala de las variables.

Antes de ajustar, suele utilizarse

$$
z_{ij}
=
\frac{
x_{ij}-\overline{x}_j
}{
s_j
}.
$$

Sin estandarización, las variables con escalas grandes reciben una penalización relativa diferente.

## LASSO {.unnumbered}

::: {#def-lasso}
LASSO minimiza

$$
J_{lasso}(\boldsymbol{\beta})
=
\left\|
\mathbf{y}
-
\mathbf{X}\boldsymbol{\beta}
\right\|_2^2
+
\lambda
\left\|
\boldsymbol{\beta}
\right\|_1.
$$
:::

La norma $L_1$ es

$$
\left\|
\boldsymbol{\beta}
\right\|_1
=
\sum_{j=1}^{p}
|\beta_j|.
$$

## Forma restringida de LASSO {.unnumbered}

$$
\min_{\boldsymbol{\beta}}
\left\|
\mathbf{y}
-
\mathbf{X}\boldsymbol{\beta}
\right\|_2^2
$$

sujeto a

$$
\sum_{j=1}^{p}
|\beta_j|
\leq
t.
$$

## No diferenciabilidad {.unnumbered}

La función

$$
|\beta|
$$

no es diferenciable en

$$
\beta=0.
$$

Por tanto, LASSO no posee una solución matricial cerrada análoga a ridge.

Se utilizan métodos como:

- descenso por coordenadas;
- subgradientes;
- LARS;
- métodos proximales.

## Subgradiente {.unnumbered}

Para

$$
g(\beta)=|\beta|,
$$

el subgradiente es

$$
\partial g(\beta)
=
\begin{cases}
\{1\}, & \beta>0,\\
[-1,1], & \beta=0,\\
\{-1\}, & \beta<0.
\end{cases}
$$

Las condiciones óptimas se expresan mediante subgradientes.

## Operador soft-thresholding {.unnumbered}

::: {#def-soft-thresholding}
El operador de umbral suave se define como

$$
S(z,\gamma)
=
\operatorname{sign}(z)
\max
\{
|z|-\gamma,
0
\}.
$$
:::

Este operador reduce la magnitud y puede producir exactamente cero.

## Caso ortonormal {.unnumbered}

Si

$$
\mathbf{X}^{\mathsf T}\mathbf{X}
=
\mathbf{I},
$$

la solución LASSO tiene la forma

$$
\widehat{\beta}_j
=
S
\left(
\widehat{\beta}_{j,OLS},
\frac{\lambda}{2}
\right),
$$

según la convención de escala utilizada.

## Geometría de LASSO {.unnumbered}

La región

$$
\left\|
\boldsymbol{\beta}
\right\|_1
\leq
t
$$

tiene forma de rombo en dos dimensiones.

Sus vértices están sobre los ejes coordenados. Las curvas de nivel de la pérdida tienen mayor probabilidad de tocar un vértice.

Por ello, LASSO produce coeficientes exactamente iguales a cero.

## Selección de variables {.unnumbered}

Si

$$
\widehat{\beta}_j=0,
$$

la variable $j$ queda excluida del modelo.

LASSO realiza simultáneamente:

- ajuste;
- contracción;
- selección de variables.

## Limitaciones de LASSO {.unnumbered}

LASSO puede presentar dificultades cuando:

- las variables están fuertemente correlacionadas;
- $p\gg n$;
- existen grupos de variables similares;
- la señal está distribuida entre muchas variables pequeñas.

En grupos correlacionados, puede seleccionar una variable y excluir otras de forma inestable.

## Elastic net {.unnumbered}

::: {#def-elastic-net}
Elastic net combina penalizaciones $L_1$ y $L_2$:

$$
J_{EN}(\boldsymbol{\beta})
=
\left\|
\mathbf{y}
-
\mathbf{X}\boldsymbol{\beta}
\right\|_2^2
+
\lambda_1
\left\|
\boldsymbol{\beta}
\right\|_1
+
\lambda_2
\left\|
\boldsymbol{\beta}
\right\|_2^2.
$$
:::

Otra parametrización es

$$
J_{EN}(\boldsymbol{\beta})
=
L(\boldsymbol{\beta})
+
\lambda
\left[
\alpha
\left\|
\boldsymbol{\beta}
\right\|_1
+
(1-\alpha)
\left\|
\boldsymbol{\beta}
\right\|_2^2
\right],
$$

con

$$
0\leq\alpha\leq 1.
$$

## Casos particulares {.unnumbered}

Si

$$
\alpha=1,
$$

se obtiene LASSO.

Si

$$
\alpha=0,
$$

se obtiene ridge.

Si

$$
0<\alpha<1,
$$

se obtiene elastic net.

## Ventaja de elastic net {.unnumbered}

Elastic net puede:

- seleccionar variables;
- estabilizar grupos correlacionados;
- funcionar mejor cuando $p>n$;
- combinar esparsidad y estabilidad.

## Caminos de regularización {.unnumbered}

Al variar $\lambda$, se obtiene una trayectoria

$$
\widehat{\boldsymbol{\beta}}(\lambda).
$$

Cuando $\lambda\to 0$, la solución se aproxima al modelo no regularizado.

Cuando $\lambda\to\infty$, los coeficientes tienden a cero.

## Valor máximo del parámetro de regularización {.unnumbered}

En LASSO existe un valor suficientemente grande

$$
\lambda_{\max}
$$

para el cual todos los coeficientes penalizados son cero.

Los algoritmos suelen construir una secuencia decreciente desde $\lambda_{\max}$.

## Selección del parámetro de regularización {.unnumbered}

La práctica habitual es seleccionar $\lambda$ mediante validación cruzada:

$$
\widehat{\lambda}
=
\arg\min_{\lambda}
CV(\lambda).
$$

También puede utilizarse la regla de un error estándar para elegir una solución más regularizada y parsimoniosa.

## Ridge como estimación bayesiana {.unnumbered}

Supóngase el modelo gaussiano

$$
\mathbf{y}
\mid
\boldsymbol{\beta}
\sim
N(
\mathbf{X}\boldsymbol{\beta},
\sigma^2\mathbf{I}
).
$$

Considérese la previa

$$
\boldsymbol{\beta}
\sim
N(
\mathbf{0},
\tau^2\mathbf{I}
).
$$

El estimador MAP minimiza

$$
\frac{1}{2\sigma^2}
\left\|
\mathbf{y}
-
\mathbf{X}\boldsymbol{\beta}
\right\|_2^2
+
\frac{1}{2\tau^2}
\left\|
\boldsymbol{\beta}
\right\|_2^2.
$$

Por tanto, ridge corresponde a una previa normal.

## LASSO como estimación bayesiana {.unnumbered}

Si la previa de cada coeficiente es Laplace,

$$
p(\beta_j)
\propto
\exp
\left(
-\frac{|\beta_j|}{b}
\right),
$$

el estimador MAP conduce a una penalización $L_1$.

## Regularización en regresión logística {.unnumbered}

La pérdida logística penalizada es

$$
J(\boldsymbol{\beta})
=
-
\sum_{i=1}^{n}
\left[
y_i\log\pi_i
+
(1-y_i)\log(1-\pi_i)
\right]
+
\lambda
\Omega(\boldsymbol{\beta}).
$$

Puede utilizarse:

- ridge;
- LASSO;
- elastic net.

## Regularización en redes neuronales {.unnumbered}

### Weight decay {.unnumbered}

Se añade

$$
\lambda
\sum_l
\left\|
\mathbf{W}^{(l)}
\right\|_F^2.
$$

### Dropout {.unnumbered}

Durante el entrenamiento, algunas activaciones se eliminan aleatoriamente.

### Early stopping {.unnumbered}

Se detiene el entrenamiento cuando el error de validación deja de mejorar.

### Data augmentation {.unnumbered}

Se generan transformaciones de los datos para reducir sobreajuste.

## Regularización en árboles {.unnumbered}

En árboles, el control de complejidad se realiza mediante:

- profundidad máxima;
- número mínimo de observaciones por nodo;
- poda;
- penalización por número de hojas.

La regularización no siempre adopta la forma de una norma.

## Regularización explícita e implícita {.unnumbered}

La regularización explícita aparece directamente en la función objetivo.

La regularización implícita puede provenir de:

- optimización;
- arquitectura;
- inicialización;
- detención temprana;
- ruido en el entrenamiento.

## Grados de libertad efectivos {.unnumbered}

En ridge, los valores ajustados son

$$
\widehat{\mathbf{y}}
=
\mathbf{H}_{\lambda}\mathbf{y},
$$

donde

$$
\mathbf{H}_{\lambda}
=
\mathbf{X}
\left(
\mathbf{X}^{\mathsf T}\mathbf{X}
+
\lambda\mathbf{I}
\right)^{-1}
\mathbf{X}^{\mathsf T}.
$$

Los grados de libertad efectivos son

$$
df(\lambda)
=
\operatorname{tr}
(
\mathbf{H}_{\lambda}
).
$$

Al aumentar $\lambda$, disminuyen los grados de libertad efectivos.

## Relación con la estabilidad {.unnumbered}

Un algoritmo es estable si pequeñas modificaciones de la muestra producen cambios pequeños en el modelo.

Ridge suele aumentar estabilidad al evitar coeficientes extremos.

La estabilidad contribuye a reducir la brecha de generalización.

## Variables categóricas {.unnumbered}

Cuando una variable categórica se codifica con varias variables indicadoras, penalizar cada coeficiente por separado puede ser inadecuado.

Pueden utilizarse extensiones como:

- group LASSO;
- sparse group LASSO.

## Group LASSO {.unnumbered}

Si los parámetros se agrupan en $G$ bloques,

$$
\boldsymbol{\beta}_1,\ldots,\boldsymbol{\beta}_G,
$$

la penalización es

$$
\sum_{g=1}^{G}
w_g
\left\|
\boldsymbol{\beta}_g
\right\|_2.
$$

Puede eliminar grupos completos de variables.

## Regularización adaptativa {.unnumbered}

Adaptive LASSO utiliza pesos:

$$
\sum_{j=1}^{p}
w_j|\beta_j|.
$$

Los pesos pueden depender de estimaciones iniciales.

Esto permite penalizar menos los coeficientes aparentemente importantes.

## Regularización y causalidad {.unnumbered}

La selección de variables predictivas no equivale a identificar variables causales.

Un coeficiente cero puede deberse a:

- correlación con otras variables;
- penalización;
- falta de potencia;
- estructura de la muestra.

La regularización mejora predicción, pero no resuelve por sí sola problemas causales.

## Conexión con R {.unnumbered}

```{r}
#| eval: false

# Requiere glmnet
library(glmnet)

set.seed(123)

n <- 100
p <- 10

X <- matrix(rnorm(n * p), nrow = n, ncol = p)

beta_real <- c(3, -2, 1.5, rep(0, p - 3))

y <- as.vector(X %*% beta_real + rnorm(n))

# Ridge: alpha = 0
ajuste_ridge <- cv.glmnet(
  X,
  y,
  alpha = 0
)

ajuste_ridge$lambda.min

# LASSO: alpha = 1
ajuste_lasso <- cv.glmnet(
  X,
  y,
  alpha = 1
)

ajuste_lasso$lambda.min

coef(ajuste_lasso, s = "lambda.min")

# Elastic net
ajuste_en <- cv.glmnet(
  X,
  y,
  alpha = 0.5
)

coef(ajuste_en, s = "lambda.1se")
```

## Ejemplo numérico ridge {.unnumbered}

Considere

$$
\mathbf{X}^{\mathsf T}\mathbf{X}
=
\begin{pmatrix}
4 & 3\\
3 & 2.5
\end{pmatrix},
$$

y

$$
\mathbf{X}^{\mathsf T}\mathbf{y}
=
\begin{pmatrix}
10\\
8
\end{pmatrix}.
$$

Con

$$
\lambda=1,
$$

se obtiene

$$
\mathbf{X}^{\mathsf T}\mathbf{X}
+
\lambda\mathbf{I}
=
\begin{pmatrix}
5 & 3\\
3 & 3.5
\end{pmatrix}.
$$

La solución ridge es

$$
\widehat{\boldsymbol{\beta}}_{ridge}
=
\begin{pmatrix}
5 & 3\\
3 & 3.5
\end{pmatrix}^{-1}
\begin{pmatrix}
10\\
8
\end{pmatrix}.
$$

Este sistema es más estable que el sistema sin penalización.

## Comparación conceptual {.unnumbered}

| Método | Penalización | Selección de variables | Estabilidad |
|---|---|---|---|
| Ridge | $L_2$ | No exacta | Alta |
| LASSO | $L_1$ | Sí | Puede ser inestable con correlación |
| Elastic net | $L_1+L_2$ | Sí | Mayor con variables correlacionadas |

## Errores frecuentes {.unnumbered}

1. Penalizar variables sin estandarizarlas.
2. Penalizar el intercepto sin intención.
3. Seleccionar $\lambda$ usando el conjunto de prueba.
4. Interpretar coeficientes LASSO como evidencia causal.

En este capítulo se estudió la regularización como mecanismo para controlar complejidad, reducir varianza y mejorar estabilidad.
